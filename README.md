I'm an AI engineer. I like building things from scratch so I understand how they work, and then putting them in front of real users.

For the last two years I worked on document AI for railway, shipbuilding, aerospace, defense and automotive projects. Mostly that meant reading engineering drawings with computer vision and OCR, and turning them into bills of materials and cable routes that people used to make by hand.

I started out studying aeronautical engineering, which is probably why I keep ending up with problems where the input is a messy drawing.

<hr>

### Things I've built

**[Readar](https://manojshendre.com/readar)** is a RAG chat engine I wrote from scratch, without a vector database or LangChain. It answers with citations, and I measured where it wasted tokens instead of guessing.

**[AGNEIS](https://agneis.manojshendre.com)** is a multi-agent framework where one planner agent decides which agents are needed and creates them while it runs. The agents work in a sandbox, own their files, and a human can pause them at any time.

**A spiking brain model** was my long side project, about two and a half years. It's a neural network built from published neuroscience that learns without backpropagation. It reached 0.81 on MNIST in a single pass, but a tiny ordinary network did better with far less compute. That taught me that copying biology is not the same as being efficient.
